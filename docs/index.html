sop-knowledge-worlds

Reusable knowledge worlds for sopworld: schemas and instances in SOP Lang, loaded by applications on demand.

Files

  • worlds/index.json: the catalog, listing worlds, schemas, shards, sources and licenses.
  • worlds/vocab.json: an English word mapped to the shards where it matters.
  • worlds/k.<world>/schema.sop and worlds/k.<world>/shards/*.sop: SOP Lang files.

Worlds

No worlds published yet.

Use from an application

1. fetch worlds/index.json and pin its version
2. for the English words of a message, look up worlds/vocab.json and get the shard paths
3. load the world's schema.sop as a sopworld module (library + core.use)
4. load only those shards (told, or as a fact provider)

The contract is in PLAN.md §2 of the repository. Shards are small; load only those that vocab.json points to for the words of the current message.

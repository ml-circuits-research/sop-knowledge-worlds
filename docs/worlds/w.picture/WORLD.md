# w.picture: depictions

A reusable world pattern, source hand-core 1, CC0-1.0. The owning types and slot
wires are authorial project declarations, not imports from a training inventory.
A picture may have a name, a background colour joined to k.colours.colour.name,
and explicit scene memberships joined to k.scenes.scene.name. Its part records
refer to the picture and an object name of k.objects.object. Repeated instances
are distinct part wires; there is no fabricated count or implicit layout.

Existing k.scenes.has describes usual parts of a scene; that is different from
these explicitly stated depicted parts. No usual part is silently instantiated.
The published lexical page sense k.words.page.noun.1 (WordNet 3.1) describes a
physical leaf side; w.dialogue.tab has a page word too. Neither is an alias of
this picture type. A host must resolve that distinction from explicit evidence.

Absent background/scene says unknown, with no default. No mood taxonomy, scene
realisation, rendering, viewport conversion, page size or native operation is
claimed. Generic std.acts can create/change/remove/query/copy declared records;
a host renderer or native tool still needs its own explicit binding.
